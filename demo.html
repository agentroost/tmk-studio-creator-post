Creator Post — Live Demo

This page demonstrates the complete Tmk Studio Creator Post integration in TikTok's Sandbox environment, using a Sandbox target account:

  1. Connect a TikTok account with TikTok Login Kit (scope user.info.basic).
  2. The connected account's name is shown (Display API / user info).
  3. Send a test video to that account's own TikTok inbox with the Content Posting API in Upload mode (scope video.upload). The video arrives as a draft notification in the TikTok app.
  4. The creator opens the TikTok app, reviews the draft, and presses Post themselves. Creator Post never publishes directly — Direct Post is not used.
